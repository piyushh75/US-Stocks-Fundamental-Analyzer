# US-Stocks-Fundamental-Analyzer
A real-time US stock screener that analyzes 4,500+ companies using financial ratios, API data, and a custom scoring engine. Built with Python, Streamlit, and the Finnhub API.

# 📊 US Stock Fundamental Analyzer – Powered by Python, Streamlit & Finnhub API

This is a real-time stock analysis app that evaluates US-listed companies based on key financial metrics — the way real analysts do.

I built this tool to help myself (and others) cut through the noise and analyze stocks using facts, not hype — using a clean, API-driven workflow with an intuitive UI.

---

## 🔍 Features

✅ Input any US stock symbol (e.g., AAPL, TSLA, AMZN)  
✅ Pull real-time data from the [Finnhub API](https://finnhub.io/)  
✅ View key metrics instantly:
- ✅ Price/Earnings (P/E), Price/Book (P/B), PEG
- ✅ ROE, ROA, EBITDA growth, Revenue Growth
- ✅ Debt-to-Equity, FCF per Share
- ✅ 52-Week High/Low, Dividend Yield, and more  
✅ Group and analyze stocks by sector or industry  
✅ Simple, interactive UI built with Streamlit

---

## 📦 Technologies Used

- Python 🐍  
- Streamlit 🌐  
- Finnhub API 📈  
- Pandas 🧮  
- Requests
